# Illustrated green mahogany assets

Created with the built-in image-generation tool. WebP encoding preserves the generated composition and transparent leaf alpha.

- `dist/mahogany-grove.webp`: softly drawn green mahogany trees on an airy off-white background.
- `dist/mahogany-leaf.webp`: green illustrated mahogany leaflet used for falling animation.
